项目概览

EasyView_Md 是一款 Markdown 编辑与多格式文件预览工具，提供桌面端和 VS Code / Cursor 插件两种形态。

  • 所见即所得的 Markdown 编辑，支持 .md 和 .mdc
  • 预览 Office 文档、PDF、图片、脑图、压缩包、音视频等格式
  • 本地历史与 Git 时间线
