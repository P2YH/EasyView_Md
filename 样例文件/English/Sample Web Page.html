Overview

EasyView_Md is a Markdown editor and multi-format file viewer, available as a desktop app and as a VS Code / Cursor extension.

  • WYSIWYG Markdown editing for .md and .mdc
  • Previews for Office documents, PDF, images, mind maps, archives, audio and video
  • Local history and Git timeline
